Política de privacidad

Última actualización: septiembre de 2026

Esta política aplica a la landing page, el sistema de mensajes y cualquier interacción por Instagram, Facebook o WhatsApp con Simón Haddad, asesor comercial de Federada Salud en Mendoza, Argentina ("nosotros", "el asesor").

Qué datos recolectamos

Solo pedimos datos que sirven para poder asesorarte comercialmente:

  • Nombre y localidad.
  • Situación laboral (relación de dependencia, monotributo o particular) y, si lo sabés, un aporte aproximado.
  • Si la cobertura es individual o para un grupo familiar.
  • Intención o plazo para cambiar de cobertura.
  • Teléfono, únicamente si vos decidís dejarlo.
  • Canal y campaña de origen (por ejemplo, si llegaste desde un anuncio o una publicación).
  • Si nos escribís por Instagram: tu nombre de usuario y el texto de tu comentario o mensaje, para poder responderte.

No pedimos ni registramos datos de salud, diagnósticos ni ninguna otra información médica sensible.

Para qué los usamos

  • Contactarte y asesorarte sobre coberturas de Federada Salud.
  • Entender de dónde viene el interés (qué publicación, campaña o canal) para saber qué contenido funciona.
  • Nunca vendemos ni compartimos tus datos con terceros ajenos a Federada Salud.

Dónde se guardan

Los datos se guardan en una base de datos privada (Supabase), con acceso restringido únicamente a Simón Haddad. Las claves de acceso nunca están en el código público del sitio.

Uso de la API de Meta (Instagram / Facebook)

Cuando comentás una publicación o nos escribís un mensaje directo por Instagram, usamos la API oficial de Meta para recibir ese comentario o mensaje y poder responderte. Esto se hace exclusivamente con la API de Instagram de Meta, cumpliendo sus Políticas de la Plataforma. No usamos ninguna herramienta de scraping ni recolectamos datos privados de tu perfil de Instagram.

Cómo pedir que eliminemos tus datos

Si quisieras que borremos la información que tenemos sobre vos (nombre, teléfono, comentarios, mensajes, o cualquier otro dato), escribinos a shaddad@federada.com indicando tu nombre y el canal por el que nos contactaste (formulario, Instagram, WhatsApp, etc.). Vamos a eliminar tus datos de nuestra base en un plazo máximo de 15 días y te vamos a confirmar por el mismo medio cuando esté hecho.

Contacto

Cualquier consulta sobre esta política o sobre tus datos, escribinos a shaddad@federada.com.
